# Web App Internationalization (EN/TH) Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use executing-plans / superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship bilingual English + Thai UI across `apps/web` with i18next, flat dotted keys, localStorage locale, and client-side API error code mapping.

**Architecture:** Web-only i18n. Catalogs under `apps/web/src/i18n/locales/{en,th}/` with `keySeparator: false`. Shell `LanguageSwitcher`. `formatApiError` maps known `code`s via `errors` namespace.

**Tech Stack:** i18next, react-i18next, Vite/React, Vitest
